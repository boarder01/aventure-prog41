# Aventure

Un jeu vu de dessus à construire mission après mission, pour apprendre la programmation
orientée objet en C++ avec Qt (cours Prog41).

**Le site : https://boarder01.github.io/aventure-prog41/**

Ce dépôt ne contient que le site : la page et les fichiers à télécharger (kit de départ,
énoncés en PDF, corrigés en archives ZIP). Il est fabriqué par un outil : son contenu ne se
modifie pas à la main.
