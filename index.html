Cours Prog41 · C++ et Qt

Aventure

Un jeu vu de dessus à construire mission après mission, pour apprendre la programmation orientée objet. Le moteur du jeu est fourni : à vous d’écrire les personnages, les monstres et les objets.

Pour commencer Les missions

Pour commencer

  1. Il vous faut Qt Creator. Le cours utilise Qt 6.8.3.

  2. Téléchargez le kit de départ et décompressez-le. Il contient le dossier moteur et le projet depart.

    Kit de départ ZIP · 32 ko

  3. Ouvrez depart/Aventure.pro dans Qt Creator, compilez et lancez. Le héros se déplace avec les flèches du clavier.

Présentation du jeu PDF · 293 ko Référence du moteur PDF · 104 ko
